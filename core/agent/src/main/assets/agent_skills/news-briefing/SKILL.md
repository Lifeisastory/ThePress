# 每日简报

1. 使用 search_news 获取所选来源的新闻，query 留空可以浏览最新条目
2. 读取 [写作规范](references/style.md)
3. 对需要整理的条目调用 read_news 获取已有摘要，新闻较多时分批读取
4. 合并同一事件，按主题分组输出简洁中文，每个事件注明来源名称
5. 明确材料的覆盖范围和来源刷新失败情况，不把抽样结果称为全部新闻
6. 只有标题时只概括标题信息，不推断具体原因和后续影响，不声称已阅读网页全文
7. 用户要求特定主题时调整 search_news 的关键词

这是基于应用资讯材料的技能，不需要脚本环境
